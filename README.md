# 🏋️ Ironary

**Track every rep, chase every PR.**

Ironary es tu bitácora de entrenamiento personal: registra cada serie, cada
repetición y cada kilo que cargas — día tras día, sin borrar tu historial nunca más.

Sabe automáticamente qué rutina te toca hoy, se adapta cuando cambias de plan,
y te muestra tu evolución real: en qué ejercicios estás mejorando, dónde te
estancas, y cuánto te toma cada sesión de principio a fin.

## ✨ Características

- 📅 Rutinas asignadas por día de la semana, con detección automática del día actual
- 🔄 Flexibilidad para ajustar ejercicios del día sin perder la plantilla original
- 📊 Registro serie por serie: peso, repeticiones y progreso histórico
- ⏱️ Seguimiento de duración de cada sesión de entrenamiento
- 📈 Visualización de progreso por ejercicio a lo largo del tiempo

## 🛠️ Stack

- **Backend:** Python + Flask
- **Base de datos:** SQL Server
- **Frontend:** HTML, CSS, JavaScript → React
- **Control de versiones:** Git + GitHub
